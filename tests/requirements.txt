# Test-only dependencies, pinned. Deliberately NOT at the repository root: a root
# requirements.txt makes a Kiro Crew registry install run pip into the gateway's
# interpreter, and adoption refuses a tree that needs a build. At runtime the app
# needs only the stdlib and aiohttp, which the gateway already provides, and the
# gateway itself.
#
# Kiro Crew is a TEST dependency here, pinned to one commit of its public source:
# the commit this app was ported from. The backend drives the host's sandbox, its
# pod runtime, its service managers, its executors and its config loader, and the
# suite (Kiro Crew's own Dev Fleet tests, moved here) exercises those real
# collaborators the way it did in Kiro Crew.
