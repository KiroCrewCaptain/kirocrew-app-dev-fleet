# requirements.txt makes a Kiro Crew registry install run pip into the gateway's
# interpreter, and adoption refuses a tree that needs a build. At runtime the app
# needs only the stdlib and aiohttp, which the gateway already provides, and the
# gateway itself.
#
# Kiro Crew itself is a TEST dependency too, but not listed here: the suite (Kiro
# Crew's own Dev Fleet tests, moved here) runs against a Kiro Crew SOURCE CHECKOUT,
# as it did in Kiro Crew, because the app manages a checkout and several tests
# discover the one the running code comes from. CI clones Kiro Crew at the commit
# in tests/kirocrew-commit.txt and installs it editable (.github/workflows/ci.yml).
